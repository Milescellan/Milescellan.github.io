03 — Projects

Selected work

Live

IoT Student Entry/Exit Monitoring System

Capstone Project

An attendance-tracking system built around UHF RFID hardware. Students, teachers, and admins each get a distinct dashboard. Every entry, exit, and staff login/logout is logged and exportable — giving teachers a verifiable attendance record for documentation and dispute resolution.

  • UHF RFID reader (JRD4035) + 860MHz tags on an ESP32, firmware in Arduino IDE
  • Laravel backend with MySQL, three role-based views (student / teacher / admin)
  • SMS notifications via Semaphore API; downloadable entry/exit records
